# 100 Pillar Documentation for AgentSwarm

This directory contains the 100 pillar content designed for SEO, AEO, and GEO optimization.
Each pillar is a comprehensive, authoritative resource that answers specific user queries
and is structured for easy consumption by AI agents and search engines.

## Structure

Each pillar file should follow this naming convention: `XXX-title.md`
where XXX is a three-digit number (001-100) and title is a kebab-case version of the pillar title.

## Optimization Guidelines

- **SEO**: Use clear, keyword-rich titles and headings. Include meta descriptions in the frontmatter if needed.
- **AEO**: Structure content to directly answer questions. Use concise lead-ins (TL;DR) and FAQ sections.
- **GEO**: Focus on entity-based content. Use schema markup where applicable and link to authoritative sources.
- **Content**: Each pillar should be comprehensive, well-researched, and provide unique value.
- **Format**: Use Markdown with proper heading hierarchy (H1, H2, H3). Include code snippets where relevant.
- **Internal Linking**: Link to related pillars and other relevant documentation.
- **External Linking**: Cite authoritative sources (Wikipedia, Wikidata, official documentation) when applicable.

## Example Pillar

See `001-introduction.md` for an example of how to structure a pillar.

## Contribution

When adding a new pillar:
1. Choose a unique number (001-100) that is not yet used.
2. Create a file with the naming convention: `XXX-title.md`
3. Follow the optimization guidelines.
4. Add a link to this README in the pillar if appropriate (optional).
5. Ensure the content is original and well-researched.
